# DATA 602 — Advanced Programming Techniques

## Overview

This repository contains Python programming and data analysis work completed as part of DATA 602: Advanced Programming Techniques in the M.S. Data Science program at the CUNY School of Professional Studies.

The coursework applies Python to data manipulation, exploratory data analysis, visualization, and analysis of real-world datasets using tools including Pandas, NumPy, Matplotlib, Seaborn, Jupyter Notebook, and Google Colab.

## Selected Project

### NYC Motor Vehicle Collisions — City Safety Analysis

Analysis of New York City motor vehicle collision data focused on identifying crash patterns, contributing factors, timing, severity, and potential public-safety insights.

**Key areas:**

- Data cleaning and preparation
- Exploratory data analysis
- Crash contributing factors
- Time-based collision patterns
- Crash severity
- Data visualization
- Public-safety recommendations

> This analysis is being developed into a standalone portfolio case study.
